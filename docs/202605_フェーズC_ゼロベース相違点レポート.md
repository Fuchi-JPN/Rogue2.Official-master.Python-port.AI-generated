## 3. 🔴致命(P0) — ゲーム進行に直接影響する相違

### P0-01: モンスター二重リストの非同期 (C-001)

| 項目 | 内容 |
|------|------|
| C版 | `level_monsters` 連結リスト1つのみ |
| Python版 | `dungeon.monsters[]` (Python list) + `dungeon.level_monsters` (連結リスト) の2構造 |
| 問題 | `Movement._kill_monster()` は `level_monsters` からのみ削除し `monsters[]` に死体残留。`DungeonLevel.clear()` は `level_monsters=None` にするが `monsters=[]` をクリアしない |
| 影響 | 死亡モンスターが `Combat._monster_at()` や `MonsterAI.mv_mons()` で参照され続ける |
| 対象 | `actions.py:_kill_monster()`, `dungeon.py:clear()` |

### P0-02: Monster フィールド別名の欠落 (C-005)

| 項目 | 内容 |
|------|------|
| C版 | `#define hp_to_kill quantity` 等14個の別名で同一メモリを共有 |
| Python版 | `hp_to_kill`, `first_level`, `last_level`, `m_damage` が独立属性として定義 |
| 問題 | `monster.hp_to_kill = 10` → `monster.quantity` は 1 のまま。`combat.py` は `hp_to_kill` を、`actions.py` は `hp` (=quantity) を減算 → 別フィールドを更新 |
| 影響 | モンスターHP管理の二重化。`hp` と `hp_to_kill` が異なる値を持つ |
| 対象 | `entities.py:Monster`, `combat.py:_mon_damage()`, `actions.py:mon_damage()` |

### P0-03: Movement.rogue_hit()/mon_hit()/mv_mons() が簡易版を使用 (C-010~012)

| 項目 | 内容 |
|------|------|
| C版 | `rogue_hit()`, `mon_hit()`, `mv_mons()` は完全実装 |
| Python版 | `actions.py:Movement` に簡易版、`combat.py:Combat/MonsterAI` に完全版の2実装 |
| 問題 | プライマリゲームプレイループ (`reg_move()` → `mv_mons()`) は簡易版 `Movement.mv_mons()` を使用。戦闘移動時も `Movement.rogue_hit()/mon_hit()` を使用 |
| 影響 | 通常プレイで: (1)ダメージ計算に `ring_exp`/`r_rings` が含まれない、(2)STATIONARY/wizard処理なし、(3)モンスターAIが大幅に簡略化（HASTED/SLOWED/FLITS/CONFUSED等すべて欠落） |
| 対象 | `actions.py:Movement`, `combat.py:Combat/MonsterAI` |

### P0-04: Xeroc(模倣体)メカニクス完全未実装 (C-028)

| 項目 | 内容 |
|------|------|
| C版 | `check_imitator()`: IMITATES フラグのモンスターは攻撃時に正体発覚→攻撃中止 |
| Python版 | `_check_imitator()` は常に `False` を返す |
| 影響 | Xeroc が地上アイテムに擬態するメカニクスが全く動作しない。通常攻撃で直接ダメージを受ける |
| 対象 | `combat.py:_check_imitator()`, `special_actions.py:_imitating()` |

### P0-05: one_move_rogue() MOVE_ON 分岐欠落 (C-020)

| 項目 | 内容 |
|------|------|
| C版 | アイテム上で拾わない場合 (`!pickup` or `levitate`)、アイテムを説明表示して `MOVE_ON` を返す |
| Python版 | この分岐が存在せず、浮遊中のアイテム説明が表示されない |
| 影響 | 浮遊状態でアイテムの上を通過した時に何も表示されない |
| 対象 | `actions.py:one_move_rogue()` |

### P0-06: fight() ループが one_move_rogue() を使わない (C-022)

| 項目 | 内容 |
|------|------|
| C版 | `fight()` ループ内で `one_move_rogue(ch, 0)` を呼び出し、移動・reg_move等の副作用を含む |
| Python版 | `Combat.fight()` は `rogue_hit()` + `mon_hit()` を直接呼び出し、移動系副作用をスキップ |
| 影響 | 戦闘コマンド使用時に reg_move() が呼ばれず、状態異常の減少やターン経過が起こらない |
| 対象 | `combat.py:fight()` |

## 4. 🟠高(P1) — ゲームバランス・ロジックに影響する相違

### P1-01: Monster.stationary_damage 型バグ (C-005)

| 項目 | 内容 |
|------|------|
| C版 | `stationary_damage` は `identified` の別名 (int型) |
| Python版 | `stationary_damage` プロパティの getter が `str(self.identified)` を返す。`+=1` で文字列連結が発生する可能性 |
| 対象 | `entities.py:Monster.stationary_damage` |

### P1-02: 連結リスト挿入順序の相違 (C-002)

| 項目 | 内容 |
|------|------|
| C版 | `add_to_pack()` は非ORIGINALで `what_is` 昇順ソート挿入 |
| Python版 | `put_m_at()` は常に prepend (先頭挿入) |
| 影響 | `Movement.mv_mons()` (level_monsters反復) と `MonsterAI.mv_mons()` (monsters[]反復) でモンスター処理順序が異なる |
| 対象 | `combat.py:put_m_at()`, `actions.py:mv_mons()` |

### P1-03: Combat.mon_hit() の m_confuse() が混乱を付与しない (C-023)

| 項目 | 内容 |
|------|------|
| C版 | `m_confuse()` は `confuse()` を呼び出しプレイヤーを混乱状態にする |
| Python版 | `m_confuse()` は `True` を返すだけで混乱を付与しない |
| 対象 | `combat.py:m_confuse()` |

### P1-04: Combat._drop_level() の経験値調整欠落 (C-023)

| 項目 | 内容 |
|------|------|
| C版 | `drop_level()` は `exp_points = level_points[exp-1]; add_exp(1,0); hp_raise()` を実行 |
| Python版 | `_drop_level()` は `hp_raise()` が `get_rand(1,10)` の簡易版、`level_points[]` 調整なし |
| 対象 | `combat.py:_drop_level()` |

### P1-05: Combat._steal_item() の機能欠落 (C-023)

| 項目 | 内容 |
|------|------|
| C版 | (1) ADORNMENT指輪の特殊処理、(2) 武器数量処理、(3) vanish() 呼び出し |
| Python版 | これら全て欠落 |
| 対象 | `combat.py:_steal_item()` |

### P1-06: アイテム自動識別の ORIGINAL 版挙動混入 (C-030)

| 項目 | 内容 |
|------|------|
| C版(非ORIGINAL) | ポーション/巻物使用後は常に `id_status = IDENTIFIED` |
| Python版 | `if id_status != CALLED: id_status = IDENTIFIED` (ORIGINAL版ロジック) |
| 影響 | プレイヤーが名前を付けた(CALLED)アイテムのid_statusが更新されない |
| 対象 | `use_actions.py:194-196, 283-285` |

### P1-07: dr_course() の mon_sees() チェック不正 (C-029)

| 項目 | 内容 |
|------|------|
| C版 | `mon_sees(monster, rogue.row, rogue.col)` は同部屋OR隣接チェック |
| Python版 | `detect_monster`/`blind` フラグ + 同部屋チェックのみ。隣接チェック欠落 |
| 影響 | 通路でプレイヤーの隣にいるモンスターがプレイヤーを認識できない |
| 対象 | `display.py:dr_course()` |

### P1-08: one_move_rogue() ドア分岐の誤実装 (C-020)

| 項目 | 内容 |
|------|------|
| C版 | DOOR + cur_room != PASSAGE → `light_passage(row, col)` のみ |
| Python版 | DOOR + cur_room != PASSAGE → `darken_room()` + `cur_room = PASSAGE` を追加実行 |
| 影響 | ドアから部屋に入る際に部屋が暗転する |
| 対象 | `actions.py:one_move_rogue()` 252-259行 |

### P1-09: UseActions._tele() の darken_room/wake_room 欠落 (C-015)

| 項目 | 内容 |
|------|------|
| C版 | `tele()` は `darken_room()` + `put_player()` + `wake_room()` を実行 |
| Python版 | `UseActions._tele()` (テレポート巻物用) は `darken_room` が `pass`、`wake_room` 未呼び出し |
| 影響 | テレポート巻物使用後に旧部屋が暗転せず、新位置のモンスターが起床しない |
| 対象 | `use_actions.py:_tele()` |

### P1-10: 幻覚時の表示文字ランダム化がC版と異なる (C-054)

| 項目 | 内容 |
|------|------|
| C版 | 幻覚は `mon_name()` (メッセージ内) のみに影響。ダンジョン表示文字は変更しない |
| Python版 | `draw_entities()` でモンスター表示文字をランダム化 |
| 影響 | 幻覚時に画面上のモンスター文字がランダムになる(C版ではならない) |
| 対象 | `display.py:draw_entities()` |

### P1-11: INVISIBLE モンスターの detect_monster チェック欠落 (C-055)

| 項目 | 内容 |
|------|------|
| C版 | `gmc()`: INVISIBLE + `detect_monster` → モンスターを表示 |
| Python版 | `draw_entities()`: `detect_monster` をチェックせず、`see_invisible`/`r_see_invisible` のみ |
| 影響 | detect_monster 効果中に INVISIBLE モンスターが表示されない |
| 対象 | `display.py:draw_entities()` |

### P1-12: show_monsters() が画面描画しない (C-056)

| 項目 | 内容 |
|------|------|
| C版 | `show_monsters()` は各モンスターを `mvaddch_rogue()` で即座に描画 |
| Python版 | `show_monsters()` はフラグ変更のみ、描画なし |
| 影響 | ポーション効果でモンスターが視認できても画面に反映されない(次回再描画まで) |
| 対象 | `combat.py:show_monsters()` |

## 5. 🟡中(P2) — 表示・操作性に影響する相違

### P2-01: メッセージ「--続きます--」が英語表記 (C-040/041)

| 項目 | 内容 |
|------|------|
| C版 | `mesg[11]` = `"［続く］"` |
| Python版 | ハードコード `" --more--"` |
| 対象 | `display.py:Message.message()` |

### P2-02: ステータスバー更新頻度不足 (C-042)

| 項目 | 内容 |
|------|------|
| C版 | 31箇所で `print_stats()` 呼び出し |
| Python版 | 約6箇所のみ有効(大部分がコメントアウト) |
| 対象 | `combat.py`, `use_actions.py`, 各モジュール |

### P2-03: インベントリ表示がスタブ (C-043/045)

| 項目 | 内容 |
|------|------|
| C版 | `get_desc()` は識別状態・素材・エンチャント値を含む完全な説明を生成 |
| Python版 | `get_item_desc()` は "ポーション" "巻物" 等のジェネリック名のみ返すスタブ。素材・色・タイトルデータは存在するが使用されない |
| 対象 | `display.py:get_item_desc()` |

### P2-04: Combat._mon_name() がスタブ (C-044)

| 項目 | 内容 |
|------|------|
| C版 | `mon_name()`: blind→「何者か」、halluc→ランダム名 |
| Python版 | `Combat._mon_name()` → `"モンスター(N)"` 固定。`MonsterAI.mon_name()` は正しいが「何か」vs C版「何者か」 |
| 対象 | `combat.py:_mon_name()` |

### P2-05: get_dungeon_char() の5実装が不統一 (C-013)

| 項目 | 内容 |
|------|------|
| C版 | 1つの `get_dungeon_char()` のみ |
| Python版 | display.py + special_actions.py + use_actions.py + combat.py + level_generator.py の5実装。プライベート版は HIDDEN ドア表示・オブジェクト文字取得が不正 |
| 対象 | 各モジュールの `_get_dungeon_char()` |

### P2-06: _zap_monster() のコピペ重複 (C-014)

| 項目 | 内容 |
|------|------|
| C版 | 1つの `zap_monster()` のみ |
| Python版 | `ThrowAction._zap_monster()` と `WandAction._zap_monster()` がほぼ同一コード。WandAction版は TELE_AWAY の表示更新欠落、DO_NOTHING メッセージ欠落 |
| 対象 | `special_actions.py` |

### P2-07: 盲目時のエンティティ描画スキップ (C-053)

| 項目 | 内容 |
|------|------|
| C版 | 盲目時 `gmc()` は `trail_char` を返し、モンスター位置には床文字を表示 |

### P2-08: _pack_letter() フォールバックの自動選択 (C-060)

| 項目 | 内容 |
|------|------|
| C版 | ユーザー入力ループ、`*` キーで一覧再表示 |
| Python版 | フォールバック時は最初のマッチアイテムを自動選択(ユーザー選択不可) |
| 対象 | `inventory.py:_pack_letter()` |

### P2-09: Combat._get_direction() が常にCANCEL (C-061)

| 項目 | 内容 |
|------|------|
| C版 | 方向キー入力を取得 |
| Python版 | `Combat._get_direction()` は常に `CANCEL` 返却。`Game._fight()` は `_get_direction_input()` で回避済み |
| 対象 | `combat.py:_get_direction()` |

### P2-10: _select_hand() 常に左手 (C-062)

| 項目 | 内容 |
|------|------|
| C版 | ユーザーが左右を選択 |
| Python版 | 常に True (左手)。右手の指輪を外せない |
| 対象 | `special_actions.py:_select_hand()` |

### P2-11: _discovered()/_call_it()/_id_trap() 未実装 (C-065~067)

## 8. 修正優先度と推奨アプローチ

### フェーズD 推奨修正順序

| 優先順位 | 対象 | 推奨アプローチ | 影響範囲 |
|----------|------|---------------|----------|
| D-01 | P0-03: 重複実装の統一 | `Movement` の `rogue_hit/mon_hit/mv_mons` を `Combat/MonsterAI` に委譲 | actions.py, game.py |
| D-02 | P0-02: Monster別名フィールド | `hp_to_kill/first_level/last_level/m_damage` をpropertyに変更 | entities.py, combat.py, actions.py |
| D-03 | P0-01: 二重リスト同期 | `_kill_monster()` と `clear()` を修正、`_monster_at()` を統一 | actions.py, combat.py, dungeon.py |
