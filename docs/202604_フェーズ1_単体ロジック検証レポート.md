## 2. 重要な相違点と問題点

### 2.1 🔴 致命的な問題 (要即時修正)

#### P1-001: ダメージ文字列解析の不完全な実装
**ファイル**: `utils.py` vs `hit.c`
**問題**: C版の`get_damage()`は`/`区切りで複数のダイスロールをサポートするが、Python版`roll_damage()`は単一のダイスのみ対応
**C版**:
```c
// "1d6/2d4" のような形式をサポート
for (j = 0; j < n; j++) {
    total += get_rand(1, d);
}
if (ds[i] == '/') { i++; }
```
**Python版**: `/`区切りを解析せず、最初のダイスのみロール
**影響**: モンスターのダメージ計算が正しくない可能性

#### P1-014: `mask_room()`の実装不備
**ファイル**: `level_generator.py:579-594`
**問題**: `_fill_it()`で`mask_room()`を呼び出す条件分岐があるが、実装が不完全
**C版 (level.c:486-489)**:
```c
if (((!do_rec_de) || did_this) ||
    (!mask_room(rn, &srow, &scol, TUNNEL))) {
    srow = (rooms[rn].top_row + rooms[rn].bottom_row) / 2;
```
**Python版**: `mask_room()`メソッドは存在するが`_fill_it()`で呼び出されていない
**影響**: 通路接続の開始点がC版と異なる

#### P1-033: ドア→通路出時の`wake_room()`未呼出
**ファイル**: `actions.py:182-187`
**C版 (move.c:112-117)**:
```c
} else if ((dungeon[rogue.row][rogue.col] & DOOR) &&
           (dungeon[row][col] & TUNNEL)) {
    light_passage(row, col);
    wake_room(cur_room, 0, rogue.row, rogue.col);
    darken_room(cur_room);
    cur_room = PASSAGE;
}
```
**Python版**: `wake_room()`が呼び出されていない
**影響**: 部屋を出る際、モンスターが正しく処理されない

#### P1-038: 気絶中のモンスター移動未実装
**ファイル**: `actions.py:check_hunger()`
**C版 (move.c:423-434)**:
```c
n = get_rand(0, (FAINT - rogue.moves_left));
if (n > 0) {
    fainted = 1;
    message(mesg[77], 1);
    for (i = 0; i < n; i++) {
        if (coin_toss()) {
            mv_mons();
        }
    }
}
```
**Python版**: `mv_mons()`のループ呼び出しが実装されていない
**影響**: 気絶中にモンスターが移動せず、ゲームバランスに影響

### 2.2 🟠 重要な問題 (早期修正推奨)

#### P1-090: `pack_count()`の引数差異
**ファイル**: `inventory.py:505-517` vs `pack.c:478-501`
**C版**: `pack_count(new_obj)` - 引数あり
**Python版**: `pack_count()` - 引数なし
**影響**: 拾得前の容量チェックで正確な計算ができない

#### P1-093: `is_wood`配列の初期化
**ファイル**: `inventory.py:142`
**問題**: `is_wood = [False] * const.WANDS` で全てFalse初期化
**C版 (invent.c:565)**:
```c
is_wood[i] = (j > MAX_METAL);
```
**影響**: ワンドの表示名が常に素材名になる

#### P1-111: ID状態更新の実装不備
**ファイル**: `use_actions.py:169-171`
**問題**: 非ORIGINALモードでは常に識別済みに設定されているが、ORIGINALモード相当の条件分岐がない
**C版**: `#if !defined(ORIGINAL)`で条件分岐
**影響**: ゲームバランスへの影響可能性

#### P1-020: `LEVEL_POINTS`配列の最終要素不一致
**ファイル**: `level_generator.py:29-33`
**C版 (level.c:56)**:
```c
99900000L  // 最終要素
```
**Python版**:
```python
99900000  // 正しい
```
**判定**: 合格

#### P1-004: ダイス文字列パーサーの`+`修飾子未対応

## 9. 結論

フェーズ1の単体ロジック検証（全131項目）では、**90項目(69%)が合格**、**31項目(24%)が要修正**、**10項目(8%)が未実装**でした。

最も重要な問題は:
1. ダメージ計算の`/`区切り未対応
2. レベル生成の`mask_room()`未使用
3. 移動時の`wake_room()`未呼出
4. 気絶中のモンスター移動未実装
5. **罠配列(`traps[]`)のセーブ対象外** → ロード後罠消失
6. **`darken_room()` 実装不備** → 盲目時等の表示がC版と不一致
7. **`add_traps()` AND/OR論理バグ** → パーティ部屋の罠配置不良
8. **`rogue_can_see()` 盲目チェック欠落** → 盲目中に視界が効く
9. **`dr_course()` 未実装** → モンスター経路設定不能
10. **`get_value()` IDテーブル非参照** → アイテム価値が不正確な可能性

これらはゲームの基本動作に影響するため、優先的な修正を推奨します。
