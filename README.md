# Rogue2 Python移植版 ＋ AI自律プレイ

古典ローグライク「ローグ・クローン2 日本語版」（C言語版）の **Python移植版** と、その上で動作する **AI自律プレイ機能** です。C言語版オリジナル（`Rogue2.Official-master` の `src/`）を基準実装として、移植・デバッグを行っています。

## このリポジトリの特徴

### 1. C言語版からの移植・デバッグはすべてAIコーディングのみで行っている

Python移植版の移植作業とその後のデバッグは、**人手によるコーディングを介さず、AIコーディングエージェントのみ**で進めています。具体的には次の方法を取っています。

- C言語版（約13,000行・約205関数）とPython版の関数・構造体・定数・グローバル変数を1対1対応させる「仕様比較表」を作成し、差分を母集団として管理しています。
  - `docs/202609_仕様比較表_C_Python対応表_v2.0.md`
  - `docs/202609_仕様比較表_C_Python対応表_v2.1_ゼロベース再検証追補.md`
- 過去の検証レポートの「修正済み」記述を鵜呑みにせず、CとPythonの**現物ソースのみを根拠に再検証**するゼロベース方式を採用しています（誤判定・改悪の混入が実証済みのため）。
- フェーズ制の検証・作業レポートを `docs/` に蓄積しています（フェーズ0/A/B/C/D、フェーズE1/E2/E3ほか）。
- 未実装コマンド・処理の横断洗い出しと対応状況は以下に集約しています。
  - `202609_未実装コマンド処理_洗い出しレポート_v1.0.md`

### 2. バグが残っていることを明示します

移植版は遊べる状態ですが、**既知のバグ・未実装・C言語版との非互換が残っています**。主なものを正直に列挙します（詳細は上記洗い出しレポート参照）。

- **セーブ・スコアのC言語版バイナリ互換なし**：現行はpickle/CSVベースで、C言語版の暗号化セーブ・スコアファイルとは互換性がありません（仕様確定待ちとして文書化）。
- **生成系の簡易化**：アイテム生成分布・祭り部屋配置などはC言語版の厳密な確率表ではなく近似実装です。
- **wizard系・オプション系の部分的未実装**：一部デバッグ用キー、`ROGUEOPT`全表などは未対応です。
- **表示・文言の近似**：アイテム説明文などは condensed 版で、340行の原典分岐の完全再現には至っていません。

Issue報告・修正プルリクエストは歓迎します。再現手順と、可能であればC言語版の該当箇所（`src/` のファイル・行番号。C言語版は別途 `Rogue2.Official-master` を参照）を添えていただけると対応が早くなります。

### 3. AIによる実プレイでバグ出しとエージェント研究を行う

ゲーム本体とは分離した `ai/` パッケージとして**AI自律プレイ機能**が付属しています。目的は2つです。

1. **バグ出し**：AIに長時間・大量にプレイさせることで、人手のプレイテストでは気づきにくいクラッシュ・状態不整合・表示崩れを検出します（実際に隣接攻撃欠落などの実バグを検出済み）。
2. **AIエージェントによるゲームプレイの研究**：状態認識・意思決定・長期ゴール管理（空腹管理、未識別アイテムの扱い、踏破と降下の判断など）を伴うエージェントの実装・改良の場としています。攻略ロジック（生存戦略・通路追従・踏破優先・高速移動など）をプロンプトとルールの両面で実装しています。

関連ドキュメント：

- `docs/rogue2-ai-autoplay-addon-design.md` … 追加機能設計書（アーキテクチャ・攻略ロジック・プロバイダー抽象・人間モニター設計）
- `docs/rogue2-ai-autoplay-implementation-report.md` … 実装レポート（追補形式の変更履歴付き）
- `docs/rougeclone2-ai-agent-spec.md` … 外部ハーネス方式の原案仕様書

## クイックスタート

### 必要環境

- Python 3.10以上、curses利用可能なターミナル（80桁×24行以上、25行以上あればAI推論ティッカー専用行が使えます）
- Windowsでは `pip install -r requirements.txt`（windows-curses）

### 手動プレイ

```bash
python3 main.py
```

### AI自動プレイ

```bash
# ルールベース（APIキー不要）
python3 main.py --ai --ai-provider scripted
# LLMプレイ（既定: OpenRouter inception/mercury-2.5-preview）
export OPENROUTER_API_KEY="sk-or-..."
python3 main.py --ai
# 高速回帰（画面なし）
python3 main.py --ai-headless --ai-max-turns 500
```

プレイ中の操作：`space`一時停止／`s`単歩／`+-`速度／`m`手動切替／`q`運転終了／`X`強制終了／`Q`ゲーム終了。ログは `ai_session.jsonl`（要約）・`ai_trace.jsonl`（全文）に記録されます（いずれもGit管理対象外）。

### テスト

```bash
python3 -m unittest test_ai_strategy test_ai_actuator test_ai_llm test_ai_observer \
  test_zero_base_regression test_main test_movement_upper
```

## ソースコードの起源（C言語版READMEより抜粋）

本移植の起点は、C言語版に付属の `README` に記された以下の系統です。

> 太田純氏の「ローグ・クローン2 日本語版1.3」、伊藤康史氏の「データ分離版ローグ・クローンII」、FUNABARA Masao氏の「rogueclone2s」、Naohiro Aota氏の「rogueclone2s-utf8」、を経て本バージョンとなりました。

> rougeclone2s（データ分離版ローグ・クローンII メンテナンスバージョンのUTF-8版）はターミナルへの出力のみが UTF-8対応となっていましたが、本バージョンは、ターミナルへの出力はもちろん、メッセージファイル、ソースコードなどすべての処理と資源がUTF-8対応しています。

> ○概略
> ダンジョンRPG.地下２７階にある宝「イェンダーの魔除け」を地上に持ち帰るのが目的。ダンジョンは冒険にでるたびに違い、セーブは不可能。

歴史まとめ（`README` より）：Rogue 3.6（1981年）→ Rogue 5.2/5.4 → Rogue Clone（1987年）→ 日本語版（1987年（株）リコー・太田純氏）→ 伊藤康史氏「データ分離版」（1992年）→ FUNABARA Masao氏「2s」→ Naohiro Aota氏「2s UTF-8」→ 鈴木維一郎氏によるC言語版（全資源UTF-8化、Linux/UNIX/Mac対応）。

ゲーム内の「運命の洞窟へのガイド」は Michael C. Toy、Kenneth C. R. C. Arnold によるオリジナルガイドの日本語訳です。Rogueは Glenn Wichman と Michael Toy により考案されました。
